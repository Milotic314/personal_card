## 1.7

**这次更新，你的人生可以更「地狱」一点。**

- **当个凝固者**：凝固度攒到 100，彻底凝固，走上一条和升华者完全相反的路。想回头？把凝固度压回 100 以下就行。连升阶咒语都换了——升华者念翠玉录，凝固者念《神曲》那句「入此门者，当弃绝一切希望」，中二感拉满。
- **副职自由职业**：不用只当打打杀杀的升华者了。现在能同时当厨魔（比谁做得更难吃）、灾厄乐师（用音乐杀人）、学者（读书读到能改世界），还能一路升星、升排名、升证数。
- **称号越挂越多**：每拿到一个副职、每升一级，身上就多一个称号。厨魔升到六星，你就是「六星厨魔」。
- **毁灭要素开局**：想一出生就是灭世级大魔王？现在可以了，称号和威权都配好。不过别飘——毁灭要素也不是全知全能的，天文会自己就是毁灭要素，照样被人算计。
- **开局时间随便挑**：133 个剧情节点塞进下拉菜单，从捡盒入局到终局之战，想从哪一幕进场都行，不用再手填日期。
- **顺手修的三件小事**：背包能一键删东西了；道具不再显示成一串乱码编号；应激期和发育期终于分清楚，AI 不会再趁你不注意直接跳级进天问之路。

## 1.6.2

**圣痕重复条目修复 + 晋升仪式语义修正 + 输出规范补全**

- **圣痕重复条目**：圣痕只有晋升成功才更新（remove 旧、insert 新，替换），日常对话/推进剧情不再反复 insert；禁止同一圣痕重复条目（修「英灵」反复追加两条的 bug）。
- **晋升仪式语义**：玩家发翠玉录咒语 = 仪式要求已全部完成，AI 只生成两个仪式方向（圣痕名 + 意象倾向，融入正文当两条道路），禁止再输出「晋升仪式要求/条件/代价」清单、不用「选项/分支」按钮式格式。
- **输出规范（新增）**：正文标签装配顺序（erii_draft→scene_card→content→meanwhile→erii_memo→UpdateVariable→options→disclaimer→StatusPlaceHolderImpl）；content 纯叙事 + 战斗检定 check 格式；幕与时间称呼（第X幕禁「段XX」、日期对时间轴）。
- **剧情索引**：改以时间为轴（日期｜事件名（第X幕）），修正日期（命运之书觉醒=2110年7月1日，原误3月3日）。
- **建档首条消息**：附「当前时间/当前地点」，触发幕文件；修圣痕显示为名称（原对象数组串成 [object Object]）。
- **圣痕形态边界**：日常/激发=外在痕迹与异象（不是能力），能力一律进技能；技能分主动（消耗源质）+被动（消耗0）两类，获得圣痕生成 1 主动 + 1 被动。

## 1.6.1

**技能写入修复 + 危险度枚举 + 末世奇观笔法红线**

- **技能写入修复**：AI 写技能「消耗」用字符串"无"，与 schema 对象不符，导致整条技能被吞、状态栏显示"无技能记录"。修：`schema.ts` 的「消耗」字段兼容非对象输入（转空对象）；变量规则明确「消耗是对象{源质/生命/修正值/歪曲度}，为 0 的键不写」；使用条件/特殊限制/破阶标签明确为数组。
- **技能必须是主动能力**：约束技能必须可主动发动（发动负荷>0 或 消耗源质>0），常驻被动/体质抗性/永久状态不是技能、写成圣痕背景说明或威权（变量规则 + 建档指令同步）。
- **里程碑条件格式兼容**：AI 写字符串数组「类型：条件」原被 `z.array(MilestoneConditionSchema)` 吞掉；改 schema 兼容字符串、状态栏晋升页兼容两种格式显示。
- **危险度枚举**：明确世界危险度四档 平静/紧张/危机/濒临毁灭（变量规则 + 状态栏读取），开局默认从「紧张」改为「平静」。
- **末世奇观笔法三禁**：`现境日常奇观` 补「三禁」——不点破"见怪不怪"、不让真相入普通人视角、不把奇观当钩子；`世界.yaml` 删掉"时间长了大家就习惯了"这句误导。
