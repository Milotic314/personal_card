# 《天启预报》地点事件库 · 落地清单（最终定稿）

> 本清单为批量落地输入。43 条挂地点事件 + 4 条通用种子 + 1 条常驻壳。
> 方向三分：日常（普通生活向，体现信息隔离下的普通世界表象）/ 战斗 / 探险。
> 目标类型五类：寻物 / 救人 / 调查 / 护送 / 击杀。
> 完成标记走 MVU `系统.已完成事件`（逗号串追加式）；完成后该地进入余波态、不再重演。
> 危险度来源：挂靠地点条目的「危险度」字段（1-5）；随机事件敌人阶位＝危险度±1阶，主线不受此限。
> 信息隔离：日常事件＝普通世界表象；战斗/探险事件＝普通人不察觉、只当怪事的暗流。

## 字段模板（每条事件正文按此展开，约 100-180 字）

```
方向：〈日常/战斗/探险〉｜目标类型：〈寻物/救人/调查/护送/击杀〉
事件性质：〈一句话：谁和谁/在争什么/发生什么〉
争夺物/目标：【唯一】〈可检验目标句〉
达成判定：〈什么算完成，可检验〉
参与NPC：〈涉事NPC/势力；复用已有 NPC 条目，无具名者用"身份+性格"占位〉
触发条件：〈时间窗/前提/玩家行为；地点维度由"玩家在该地"天然满足〉
完成后标记：〈登记 ID→追加进已完成事件；余波＝场景变化+NPC状态，不再重演〉
收尾：〈结算→场景收束→事件关闭；禁止延伸〉
失败收尾：〈失败/放弃的结算与后果，不悬置〉
```

## 落地技术口径

- **type**：新建「随机事件」，加入 `typeLists.before_char`（在地理之后）。
- **strategyThresholds**：`随机事件: 0`（selective）；L1 壳用 `scope: catalog`（constant）。
- **position**：before_char（configure 按 typeLists 推导）。
- **contents**：`<地点事件 id="xh01">` + 文件 + `</地点事件>`。
- **keywords**：地点名 + 别名 + 事件性质词（每条 3-6 个，避单汉字、避泛用词）。
- **part**：可不设（简单类型），或用「新海/丹波/边境/地狱」分组。
- **文件**：`世界书/事件/地点事件/xh01-深夜来客.yaml`（按 ID 前缀分目录）。
