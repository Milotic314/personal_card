# CONTEXT.md ·《天启预报》领域词汇表

> 单一语境入口：模型与人全程用同一套词。每个关键概念先定规范名，再列禁止误称。新增概念先补本表再动手。
> 依据：guguskill 阶段 0（领域建模）；资料库 v3 与 04_角色 命名对照。

## 1. 时间线语言

**段（篇章）**：剧情时间线的最小单位（段00-27）。段条目是候选事件库（条件触发），不是必须按序推进的剧本。
_避免_：卷、章、篇（混用）；"必须按时间切换篇章"（条件触发而非必须切换）

**时间锚点**：段内事件的日期定位（如 2110年03月03日）。推算日期须标"约"或"（编辑演算）"。
_避免_：把推算日期写成确定日期

**剧情索引**：段00-27 的导航表（时间线参考，非强制顺序）。
_避免_：把剧情索引当"必须按序推进"的命令

**编辑演算**：没有绝对依据的日期、换算，明确标注为推算，不冒充官方设定。
_避免_：将编辑演算当作原作明示

## 2. 人物档案词汇

**主役 / 重要角色 / NPC**：三级人物条目（主役完整模板、重要精简、NPC 极简）。槐诗为世界核心角色（AI 扮演的客观存在）。
_避免_：把槐诗当玩家化身/工具人；把贯穿角色（X女士、所罗门等）漏出总览

**玩家角色**：玩家完全自由自定义的原创角色，能力走原作体系（阶位/圣痕/谱系/学者）。
_避免_：视角角色、固定主角、预设玩家身份

**知识边界**：角色只能知道当前阶段亲历或被可靠告知的事。
_避免_：角色知道原著真相、知道玩家未说之事

**阶段一致**：状态变化（记忆/身体/阵营/契约/能力）后称呼、亲密度、战斗习惯同步改变，后期成果不倒灌前期。
_避免_：早期角色使用后期能力（能力时间线隔离铁律）

**能力时间线隔离**：卡面时间点之前的能力一律不可用（只约束 NPC；玩家不受限，能力获取=事件因果）。
_避免_：按"剧情后期"提前使用后期能力

## 3. 世界设定词汇

**现境 / 边境 / 地狱**：三界结构（人类文明庇护所 / 主权稀薄的过渡地带 / 旧世界残骸堆积的已死世界）。
_避免_：把地狱当普通魔界/死后世界

**圣痕 / 谱系 / 阶位**：圣痕=升华者的力量烙印（分谱系）；阶位=应激期→水银→黄金→以太→星锑→贤者之石→天敌。
_避免_：阶位混称（贤者之石/哲人之石统一）；谱系名混用

**毁灭要素**：二十四、两两相对，完成前提即必能毁灭现境的东西。
_避免_：毁灭因素（误称）

**三大封锁**：查拉图·斯特拉如是说（物理规则秘仪）/ 万物终亡（死亡概念）/ 彩虹桥（现境-边境统和）。
_避免_：查拉图斯特拉（漏"·斯特拉如是说"）、大密仪（混称；大秘仪=查拉图封锁的另一称谓，规范用"大秘仪·查拉图斯特拉"或全称）

**命运之书**：天国谱系源典与目录（槐诗金手指；真书在他处，象牙之塔馆藏为赝品）。
_避免_：把赝品当真书；"金手指"等读者向词汇

**帝夋**：彤姬旧名（日主，东夏诸神之主；原文作"帝夋"）。
_避免_：帝俊、帝浚（异写，以帝夋为主）

## 4. 变量词汇

**stat_data**：MVU 状态树（唯一可变状态层；记录状态，不承载原作资料）。
_避免_：把设定/资料写进变量

**JSON Patch**：变量更新的唯一写入路径（add/replace/remove/move；path 以 / 开头；无变化写 []）。
_避免_：界面/世界书直接改变量；模型用自然语言描述更新

**已完成事件**：追加式记录（如 hm01,hm02），只增不删，防地点事件重复触发。
_避免_：删除/覆盖已完成记录

**当前目标**：探险单槽位（同时只追踪 1 个活跃目标）。
_避免_：数组多目标

**随机事件开关**：全局 on/off（对话指令切换）。
_避免_：方向级开关未实现时提前使用

## 5. 界面词汇

**状态栏**：MVU 之后的前端只读界面（概览条+分区详情），只读不改变量。
_避免_：界面直接写 stat_data

**入世卷**：开局建卡流程（轻量版=对话式五步建档；远期=交互式表单）。产物为【玩家角色档案】。
_避免_：把入世卷当普通开场白；绕过建档直接开局

**正则占位符**：状态栏等界面通过占位符（如 <StatusPlaceHolderImpl/>）由正则替换渲染。
_避免_：正则做数据解析（只定位不解析）

## 6. 战斗词汇

**检定（check）**：1d20+修正 vs DC 的公开判定（只结果不确定且失败有代价时检定）。
_避免_：无检定必要时的随意掷骰；挑骰/补骰/重掷

**骰池**：每次生成的一次性 d20 骰池（12 个，从左到右取用，作废不补）。
_避免_：为剧情挑骰、补骰、重掷

**破阶**：防守方公开阶数高至少 2 个完整阶位=无法破阶（除非破阶许可：炼金武器破阶标签/已知克制/暴露弱点/陷阱束缚/合法临时阶位）。
_避免_：自然 20 凭空破阶；低阶硬撼高阶

**阶位档值**：（阶数-1）×3+小位值（下=1，中=2，上=3）。
_避免_：把阶位未知当不入阶
