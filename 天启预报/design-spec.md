# Design Spec — 天启预报

> 同人角色卡 · 基于风月《天启预报》（起点中文网，2019-2023，约 629 万字）改编。
> 资料源：`D:\写卡测试\天启预报资料\资料库\`（00-17 全套，含能力时间线隔离铁律）。

## 项目定位

- **项目名称**：天启预报
- **形式**：角色卡（chara_card_v3，世界书内嵌，世界书驱动——与参考卡 Re0 同构）
- **主题**：同人改编 / 都市超凡冒险 / 角色扮演
- **体验目标**：沉浸代入《天启预报》的现境世界——与槐诗及他的伙伴们同行，从新海市的小巷卷入现境与地狱的万年棋局，在吐槽与中二之间，见证"一万零一种拯救世界的方法中，选一个通往 HAPPYEND 的方向"。
- **情感落点**：陪伴 + 燃 + 治愈（原作结局为 HE，卡面基调同源）

## 玩家角色（核心决策）

- **玩家不扮演槐诗**。玩家拥有自己的角色：身份、来历、能力由玩家自定义。
- 卡面提供**玩家角色引导**（世界书条目 + 开场白留白）：可选身份示例——新海本地居民 / 天文会新人干员 / 特事处文员 / 边境流浪者 / 异国升学新生 / 被异常卷入的普通人；与槐诗的初始关系可选项——陌生偶遇 / 同校同学 / 邻居 / 被卷入同一事件的目击者。
- **AI 扮演**：槐诗（主役，完整模板）＋ 所有原作角色（乌鸦、艾晴、柳东黎、罗娴、莉莉、傅依、白帝子等）。玩家角色的言行自由，世界按原作规则回应。

## 世界观概念

半架空：现代都市（公元 2110 年的东夏共和国）＋ 超凡组织暗层。核心差异：

- **三界结构**：现境（人类文明，三大封锁庇护）→ 边境（日常之后的异常）→ 地狱/深渊（诸神黄昏后由旧世界残骸堆积成的"已死去的世界"，深度越深越危险）。
- **三大封锁**：查拉图·斯特拉如是说（物理规则秘仪）、万物终亡（死亡概念）、彩虹桥（现境-边境统和）。
- **力量体系**：学者与升华者；阶位应激期→水银→黄金→以太→星锑→贤者之石→天敌；圣痕与谱系（天国谱系·天问之路：阴魂→山鬼→少司命/大司命→云中君→东君→太一）；源质为一切根基。
- **毁灭要素**：二十四个、两两相对，天文会评定"完成前提即必能毁灭现境"。
- **主角线**：槐诗，17 岁穷学生→灾厄乐师→……→天敌·太一；金手指=命运之书。

## 角色方向

- **主役（AI 扮演）**：**槐诗**——东夏新海市 17 岁穷困大提琴手，孤儿（父母卷款潜逃的假象背后是灭门真相），捡到刻满图腾的铁盒，乌鸦苏醒，命运之书激活。性格：咸鱼乐天、嘴硬心软、毒舌但心软、不肯伤人；从"我要杀了他"的复仇出发，逐步坚定"我要保护我的家人"的梦想。成长弧贯穿 27 篇章（段00-27，终局为原文级 10 篇）。
- **重要角色（AI 扮演）**：乌鸦/彤姬（导师·军师·金主·契约者，解说狂魔）、艾晴（天文会监察官，轮椅少女，面冷心黑的好女孩）、柳东黎（会所一哥/暗线监察官，谜语人损友）、罗娴（纯真凶残的武道天才）、莉莉/海拉（贤者之石的人造人）、傅依（班长/好兄弟）、白帝子（路痴五阶少女）。
- **玩家角色**：见上，自由自定义，卡面给引导。
- **NPC·非人**：老杨、王海、红手套、凶猿、戚问、戚元、房叔、浮士德、老肖、玄鸟、罗老、符残光等——极简条目，按需命中。

## 剧情设计

- **时间结构诊断**：单线推进（2110 新海开局 → 约 2113 诸界之战/天国计划），有历史回溯与回忆线（序章 2020 珠穆朗玛"最后的晚餐"、白冠王尾声、魔女之梦），但主线线性。无轮回机制。
- **三层颗粒度**：
  - 宏观层：时间线条目（常驻，从诸神黄昏到 2110 的浓缩编年史）
  - 中层：剧情索引条目（常驻，27 篇章 + 时间锚点，一卡一表）
  - 微观层：段条目（after_char / selective，段00-27，每段 4~6 事件，事件五要素）
- **能力时间线隔离（铁律）**：按 `17_能力时间线隔离` 执行——早期槐诗不得使用后期能力（东君/太一/怨憎/铸造者等）；玩家角色若为升华者，其能力由玩家自定并受世界规则约束。
- **同人改编**：三准则（叙事基调/蝴蝶效应/防全知）置顶常驻。原作是锚点不是剧本；玩家与槐诗的行动可以改变剧情走向。

## 风格意向

- **叙事视角**：第二人称叙述（"你"）为主，玩家所见即所得；槐诗与配角按各自语气速查扮演。
- **语言风格**：风月式——"吐槽流外壳 + 中二浪漫内核"。叙述者随时下场吐槽（游戏梗/市井大白话），燃点处报家门式宣言；抒情克制留白。
- **比喻方向**：优先音乐（琴弦/音色/交响/乐章）与炼金锻造（铁/火焰/源质）两大意象库；力量描写给"工艺过程"。
- **描写侧重**：环境/动作场景用"短句断行、四字顿挫、近景-特写-远景"镜头；设定解说用"正史腔+弹幕腔"交替；战斗用"静→动→后果→余韵"四拍。
- **情绪基调**：热血 + 搞笑 + 温情 + 克制的悲壮。

## 开场构思

- **时间点**：公元 2110 年，新海市——命运之书觉醒前夜（与段条目第①段一致）。
- **场景**：海港城市新海的黄昏/夜晚，玩家角色以自定义身份在场（初到新海 / 本地生活 / 恰逢其会），与"某件事"擦肩——黑心中介、码头爆炸、小巷里递出铁盒的垂死者，三者其一作为事件引线，给玩家自然切入点。
- **信息密度**：渐进揭示，留白悬念（不抛设定堆）。
- **首步引导**：弱引导——场景与角色在场，玩家自由选择如何介入（旁观/搭话/跟上去/报警）。
- **开场形式**：叙事式（300~600 字）。

## SFW / NSFW

- **内容分级**：默认 **SFW**。原作主角槐诗开局 17 岁（高中生），卡面涉及大量未成年人角色（槐诗、傅依、白帝子、原照等），**硬性边界：不写未成年角色的情色内容**；成年角色间的亲密内容仅限玩家主动、自然推动的范畴，克制约束。
- **感情线**：尊重原作多线暧昧（彤姬/艾晴/罗娴/莉莉/傅依/白帝子），不强行撮合、不替玩家决定；玩家角色的感情线自由发展。
- 其余维度：暂不讨论，按"内容干净、情感真挚"处理。

## 技术收尾（2026-08-28 修订）

- **MVU 变量**：做（2026-08-28 用户拍板）。追踪：玩家档案（战力/圣痕能力/成长里程碑/当前武器/状态）、NPC 在场布尔表、系统（已完成事件/随机事件开关/当前目标）、世界（当前时间/地点/事件）；schema 参照参考卡2（龙族）架构 + 本卡功能，详见创作规划.yaml mvu 段。
- **战斗系统**：C 档 d20 叙事回合制（参照参考卡2），含破阶机制（阶位碾压落地）。
- **状态栏 / 变量美化**：做（依赖 MVU；ui_mode=frontend，tavern-ui 阶段）。
- **EJS**：仅战斗规则条目的内联骰池（参照参考卡2），其余不用。
- 打包：tavern-cards-forge → chara_card_v3（先 json artifact，后续补头像可改 png）。

## 开放问题（留给创作阶段）

1. 玩家角色在开场时的具体位置与身份，由开场白留白 + 玩家自定义（不写死）。
2. 段条目颗粒度：18 篇 × 5~8 事件，是否需要在 05 剧情资料基础上进一步压缩到每篇 4~6 事件（体量控制），创作阶段裁决。
3. 人物条目总量与分级名单，人设阶段按 doujin-character 三级模板裁决。
